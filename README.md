# StudySpace — UI/UX Design Project

## Overview
StudySpace is a student productivity dashboard designed to help students organize their tasks, deadlines, and weekly schedules in one calm, minimal interface.

## Problem
Students often need to switch between multiple tools to manage assignments, events, and study sessions. StudySpace aims to make weekly planning more organized and less overwhelming.

## Goals
- Create a clean, easy-to-navigate dashboard.
- Display upcoming tasks and deadlines clearly.
- Include a compact weekly calendar.
- Design for desktop first, then adapt the interface for mobile.

## Design Process
1. Define the problem and intended users.
2. Plan the dashboard layout.
3. Create low-fidelity wireframes in Figma.
4. Develop the visual design.
5. Test the layout and refine the experience.

## Tools
