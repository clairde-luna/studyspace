# StudySpace — UX Case Study

## 1. Project Overview
**Project type:** Student productivity dashboard  
**Role:** UI/UX Designer  
**Tools:** Figma, GitHub  
**Status:** In progress

## 2. The Problem
Students may find it difficult to keep track of assignments, deadlines, and study sessions across multiple tools.

## 3. Design Goals
- Make weekly planning easier.
- Present upcoming tasks clearly.
- Create a calm, minimal interface.
- Support both desktop and mobile layouts.
